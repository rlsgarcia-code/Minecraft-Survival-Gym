# README image provenance

- `minecraft-gym-hero.png` is illustrative artwork generated for this project
  with OpenAI's built-in image generation tool on 2026-11-23. It is not an
  experiment result or an application screenshot.
- `brincabot-observer-live.png` and `brincabot-spatial-map.png` are captures of
  the local BrincaBot Observer research application on 2026-11-22.
- `voxel-memory-audit.png` is a generated project audit artifact produced by
  `scripts/audit_voxel_memory.py`; it compares canonical 3D voxel memory with a
  derived 2D navigation projection.

The hero prompt requested a wide, text-free voxel research scene showing an
embodied agent, RGB-D perception, spatial navigation, and learning telemetry.
No generated image in this directory should be interpreted as benchmark
evidence.
